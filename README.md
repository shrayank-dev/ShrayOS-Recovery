## 🚀 Quick Start

Clone the repository

```powershell
git clone https://github.com/YOUR_USERNAME/ShrayOS-Recovery.git
```

Open the folder

```powershell
cd ShrayOS-Recovery
```

Run

```powershell
.\Setup.ps1
```

Done.
